# Cybersecurity Lab Setup - Week 1 (WK1-PM1)

A cybersecurity testing lab built using VirtualBox and Kali Linux.

## Requirements Met
- VirtualBox as base
- Kali Linux as attacking machine
- NATNetwork subnet 10.0.0.0/24
- Clipboard & drag/drop enabled (Bidirectional)
- Shared folder /downloads from host
- Kali IP: 10.0.0.2/24
- Full Internet access
- Snapshot taken
